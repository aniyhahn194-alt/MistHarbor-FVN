# V0.5 美术 / UI 说明：风格规范、本轮做法与限制

版本：`0.5.0`。配套文档：[V0.5-STATUS.md](V0.5-STATUS.md)（已实现 / 未实现 / 测试结果）、[ART_BRIEF.md](ART_BRIEF.md)（给画师的完整需求，仍然有效）。

> **先说清楚**：本轮所有新增 / 改动的美术（背景、立绘后期、加载画面、界面图）都是**用 Python + Pillow 写代码画出来、或对代码绘制的占位图做程序化后期**的结果，
> **不是专业手绘美术，也没有使用 AI 图像生成工具**（本环境未提供）。它的作用是把风格、色彩、构图和加载体验先统一起来，让作品“看起来是同一个世界”，
> **不能**当作最终的正式角色立绘 / 背景；正式美术仍需要画师绘制（需求见下文第 4 节与 [ART_BRIEF.md](ART_BRIEF.md)）。

## 1. 风格规范：夜雾港口

**一句话**：深夜的港口，冷青的雾，只有灯是暖的。

| 元素 | 规则 |
| --- | --- |
| 基调 | 画面 80% 以上是深蓝 / 冷青；暖金只出现在“光源”上（路灯、灯塔、吊灯、提灯、窗），像雾里被点亮的几处 |
| 核心意象 | 雾气、港口（栈桥 / 栏杆 / 缆桩 / 船影）、灯塔与光束、夜空与月、湿润地面上灯光的倒影 |
| 光向 | 冷光来自月亮 / 雾（左上）；暖光来自两角色之间的灯。所以角色**朝向画面中央的一侧**是暖金边缘光，**外侧**是冷青边缘光 |
| 构图 | 左右两侧站角色（x≈4% / 96%），**中央放灯 / 灯塔 / 门**作视觉焦点；下方约 1/3 被对话框遮挡，所以重要内容在上 2/3；四角压暗（暗角）收住视线 |
| 质感 | 低饱和、柔光、少量颗粒（掩盖暗部渐变色带）；不用高饱和荧光色；全画面唯一的高饱和红是灰舟的围巾（视觉锚点） |
| 动态（克制） | 雾漂移、灯光呼吸、角色呼吸（4px）、标题淡入；全部是 ATL 的 alpha / 位移缓动，无粒子、无着色器 |

## 2. 本轮做了什么

### 2.1 加载画面（三层，风格一致）

| 位置 | 文件 | 说明 |
| --- | --- | --- |
| Web 页面加载（presplash） | 仓库根目录 `web-presplash.png`（1600×900） | 标题“雾港来信”+ 灯塔光束 + 两盏路灯 + “正在启程 LOADING”。**注意**：Ren'Py 官方**命令行** `web_build` 不会应用它（见下），所以 `tools/build_web.sh` 在官方构建后补做了 Launcher 图形界面本来会做的事，并校验产物 |
| Web 加载状态条 | `tools/verify_web_build.py` 向产物 `index.html` 注入一小段 CSS | 把官方默认的“黑底 + 浏览器原生蓝色进度条”改成深蓝底、冷青描边、暖金进度条（`accent-color`）。只改外观，不动加载逻辑；文字（如 `Unpacking...`）仍是官方英文 |
| 桌面启动 | `game/presplash.png`（960×540） | Ren'Py 在引擎初始化前自动显示；桌面最短保留 1.2 秒（`config.minimum_presplash_time`），Web 不额外等待 |
| 游戏内 splashscreen | `game/splash.rpy` + `game/gui/splash.png` | 同一幅标题画面淡入（ATL：透明度 + 轻微缩放回落）→ 停留 2.2 秒（点击 / 触屏 / 按键可跳过）→ 淡出到主菜单。读档、重新开始、结局返回主菜单都**不会**再次进入；`renpy.sh ... test` 下自动跳过，以保证 testcase 仍从主菜单开始 |

> **官方 CLI 的 Web presplash 问题**：Ren'Py 8.3.7 的 `launcher/game/web.rpy` 里，`web_build` 命令行入口把 presplash 的查找路径写成 `project.current.path`，
> 而命令行模式下 `project.current` 不是被构建的项目，所以项目根目录的 `web-presplash.png` 被忽略，`index.html` 仍引用默认的 `web-presplash.jpg`。
> 实测：不做后处理时，产物里的 `index.html` 仍是 `web-presplash.jpg`。Launcher 图形界面里点 “Build Web Application” 不受影响。

### 2.2 背景（重绘，`tools/generate_v05_art.py`）

三张背景都按“夜雾港口”重绘（仍是 1280×720 的代码绘制图）：

- **栈桥**：深蓝夜空与月、雾、远处灯塔与光束、两盏暖金路灯立在两角色之间、货船剪影（亮两扇窗）、湿木板上的灯光倒影、近景压暗
- **后巷**：冷青蓝砖墙、中央木门门缝漏暖光、一盏暖金吊灯、三扇暖窗、水渍反光、门边木桶
- **灯塔**：星空、月、灯塔居中偏右（避开角色面部）、光束扫过海面、塔身受光、护栏上一盏小灯、海面灯光倒影

所有背景加了暗角与极轻的颗粒。构图上把亮点（灯、灯塔、门）放在两角色之间，两侧留给角色；比 V0.2 的“灰蓝白天感”背景更暗、更有层次，**画面不再空**，但仍是几何风格的程序化图，细节有限。

### 2.3 立绘（程序化后期，不是重画）

对 `tools/generate_assets.py` 画的原始立绘（形象、表情不变）做一轮后期（`stylize_sprite`）：

| 处理 | 目的 |
| --- | --- |
| 降饱和 + 冷青蓝色罩 + 略压暗 | 与背景统一配色（灰舟偏冷、林岚保留橘色但更低调） |
| 越靠近脚下越被冷青雾色吞没 | 让人物“站在雾里”而不是浮在前面 |
| 朝灯一侧叠暖金光 | 暖光方向与场景灯的位置一致 |
| 轮廓羽化 + 冷青 / 暖金边缘光（取代硬描边的一部分） | 去掉“贴纸”的硬边 |
| 外圈一层冷青雾晕（背光） | 人物与背景之间有环境光过渡 |
| 脚下柔和投影 | 接地感（**注意**：对话框默认会遮住腿脚，所以只有选项页 / 无对话框时才能看到） |
| 画布四周加留白（640×1040 → 720×1140） | 给光晕与投影留空间，避免裁切 |

游戏内：缩放仍为 0.56，站位仍为左右两侧；新增 4px 呼吸（两人周期 / 相位不同）；场景灯光的暖金光晕随背景一起“呼吸”（只做 alpha 缓动）。

**限制**：形象仍是几何块面的占位造型，后期只能改善融合度，**不能**改善造型、解剖、表情的专业度；脸部细节、毛发质感、手部、服饰褶皱都没有改善。

### 2.4 界面一致性（`tools/generate_ui.py`）

- 对话框 / 姓名框 / 快捷按钮 / 选项按钮：统一 16px 圆角、冷青 2px 描边、顶部一道很淡的冷白内高光；选项的灯点带光晕（悬停变暖金）
- 对话框顶边下加一层冷青微光，与按钮高光呼应；对话框底色不透明度提高到 96%，避免立绘的腿脚透出来
- 主菜单底图改为读取新灯塔背景（压暗幅度由 0.38 降到 0.20，因为新背景本身已是夜色）
- 布局、尺寸、字号、点击区域**没有变**（保证 V0.2 已验证的手机横屏触控尺寸不退化）

## 3. 手机横屏

本轮以美术为主，**没有改动布局与触控尺寸**，沿用 V0.2-P1 的结果（快捷按钮高 80px≈43 CSS px 等）。验证方式是桌面 Chromium 的视口模拟（844×390 等），**不是真机**，见 [V0.5-STATUS.md](V0.5-STATUS.md)。

## 4. 给专业美术的需求更新（相对 ART_BRIEF.md V0.2-P1 的补充）

[ART_BRIEF.md](ART_BRIEF.md) 的角色设定、表情清单、背景清单、格式与授权要求**仍然有效**。V0.5 增加以下说明，便于画师直接交付能与现有 UI / 动效配合的素材：

1. **色彩与光向**：按本文第 1 节的色板与光向绘制。立绘请直接画出“冷青边缘光 + 暖金边缘光”（外侧冷、朝向画面中央的一侧暖），不要依赖程序后期；游戏里的后期只做微调。
2. **立绘留白**：画布四周建议保留 ≥ 5% 的透明留白（V0.5 的占位图为 720×1140，比 640×1040 多出 40px 左右 / 30px 上 / 70px 下），脚下可直接画柔和投影，或交付单独的投影层。
3. **差分对齐**：同一角色所有表情同一画布、同一轮廓，V0.5 的呼吸动画（整体 y 位移 4px）要求脚底落在画布底边以上固定距离，不要在差分之间改变脚底位置。
4. **背景分层**：天空 / 海 / 远景 / 中景 / 前景 / 灯光（光晕单独一层）/ 雾，分层交付。V0.5 已有“灯光呼吸”和“雾漂移”两类动效，灯光层可以直接替换 `gui/fx/fx_glow.png` 的位置。
5. **灯与角色的相对位置**：栈桥 / 后巷 / 灯塔三景的暖光源请放在两位角色之间（x≈35%–65%），角色面部（x<28% 与 x>72%，y 约 15%–50%）不要与亮点重叠。
6. **加载 / 标题画面**：需要一张正式标题插画（16:9，建议 3840×2160，留出标题位置）替换 `web-presplash.png` / `game/presplash.png` / `game/gui/splash.png`；这三张的构图应保持一致，因为 Web 加载画面与游戏内 splash 是接续显示的。标题字用游戏字体（思源黑体，OFL）或授权明确的字体，**新增字体必须核对许可**。
7. **授权**：不接受网络抓取图、AI 生成但授权不明的图；交付物需附授权说明，并补充到 [THIRD_PARTY_NOTICES.md](../THIRD_PARTY_NOTICES.md)。

## 5. 重新生成素材

```bash
pip install pillow
python3 tools/generate_assets.py        # V0.1 的原始背景 / 立绘（会被下一步覆盖背景，立绘在下一步被后期）
python3 tools/generate_v05_art.py       # V0.5：重绘背景、立绘后期、web-presplash / presplash / splash
python3 tools/generate_ui.py            # 界面图；主菜单 / 游戏菜单底图读取上一步的背景
```

`generate_v05_art.py` 每次都在内存里重新绘制原始立绘再后期，重复运行不会叠加处理。
