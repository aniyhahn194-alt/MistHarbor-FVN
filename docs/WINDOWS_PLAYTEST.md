# Windows 试玩与构建指南（零基础版）

适用版本：V0.1.0。本文分三部分：**A 直接运行发行包**、**B 自己安装 SDK 运行/构建**、**C 试玩清单**。

> 状态说明（如实）：Windows 发行包（zip）已在 Linux 上用 Ren'Py 官方 `distribute` 命令构建成功，
> 并且解压后的包内容已用 Ren'Py 8.3.7 的 Linux 运行时做过 lint 和自动通关测试。
> **`MistHarbor.exe` 本身还没有在真实 Windows 上启动过**，这正是需要你亲自验证的部分。

---

## A. 直接运行发行包 `MistHarbor-0.1.0-win.zip`

1. 把 zip 放到**纯英文、无空格的路径**，例如 `D:\Games\`（避免中文/特殊字符路径带来不必要的麻烦）。
2. 右键 zip → “全部解压缩…”，解压到 `D:\Games\MistHarbor-0.1.0-win\`。**不要直接在 zip 里双击运行。**
3. 打开解压后的文件夹，双击 `MistHarbor.exe`。
4. 如果 Windows 弹出蓝色“Windows 已保护你的电脑”（SmartScreen）：这是因为程序没有付费代码签名，
   点“更多信息” → “仍要运行”。如果杀毒软件拦截，请把该文件夹加入信任（程序内容可对照源码仓库）。
5. 第一次启动可能需要几秒钟；应看到标题为“雾港来信”的窗口，左侧是中文菜单。

存档位置（需要重置进度时可删除）：`%APPDATA%\RenPy\MistHarbor-FVN-0.1\`
（在资源管理器地址栏输入 `%APPDATA%\RenPy` 回车即可）。

## B. 自己安装 Ren'Py SDK、运行和构建

### B1 安装 SDK
1. 打开 https://www.renpy.org/latest.html ，下载 Ren'Py **8.3.7**（或更新的 8.x）SDK，Windows 版是 `renpy-8.3.7-sdk.zip`（或安装包）。
2. 解压到英文路径，例如 `D:\renpy-8.3.7-sdk\`。

### B2 获取项目
- 方式一（推荐）：安装 Git，执行 `git clone https://github.com/aniyhahn194-alt/MistHarbor-FVN.git`，
  再切换到开发分支：`git checkout cursor/v0-1-prototype-1d4f`。
- 方式二：在 GitHub 的 PR #1 页面点 “Code → Download ZIP”，解压。

### B3 导入并运行
1. 双击 SDK 里的 `renpy.exe`，打开 Ren'Py Launcher。
2. 点左侧 **Preferences（设置）** → **Projects Directory（项目目录）** → **Change**，
   选择**包含 `MistHarbor-FVN` 文件夹的上一级目录**（例如项目在 `D:\Projects\MistHarbor-FVN`，就选 `D:\Projects`）。
3. 回到首页，项目列表里应出现 `MistHarbor-FVN`；点它，再点 **Launch Project（启动项目）**。

### B4 语法检查（可选）
选中项目 → 右侧 **Check Script (Lint)**。预期：显示统计信息，没有 error。

### B5 构建 Windows 发行包
1. 选中项目 → **Build Distributions（构建发行版）**。
2. 在列表里勾选 **Windows**（可取消 Linux/Mac），点 **Build**。
3. 完成后点 **Open Directory**，在项目同级的 `MistHarbor-0.1.0-dists` 文件夹里找到 `MistHarbor-0.1.0-win.zip`。

（Linux/macOS 命令行：`tools/build_windows.sh <SDK目录> [输出目录]`，已在 Linux 上验证；Windows 上请用 Launcher。）

## C. 试玩清单（打勾记录）

提示：每个选项旁边的“+2/+1/0/−2”是内部信任度变化，游戏里不会显示数字，只会弹出“林岚对你的信任提高/降低了”的提示。

### C0 启动与主菜单
- [ ] 双击 `MistHarbor.exe` 能启动，没有报错弹窗
- [ ] 标题栏/窗口显示“雾港来信”，窗口图标是一只狼头
- [ ] 主菜单是中文：开始游戏 / 读取游戏 / 设置 / 关于 / 帮助 / 退出，文字清晰、没有方块字
- [ ] 背景是雾中的栈桥，左下角显示“雾港来信”和版本号 V0.1.0
- [ ] 点“关于”能看到介绍文字，点“返回”能回到主菜单

### C1 开始游戏与角色对话
- [ ] 点“开始游戏”，画面淡入，出现栈桥背景和旁白
- [ ] 单击鼠标 / 按空格 / 按回车 都能推进对话
- [ ] 出现“信封”卡片（收信人：灯塔看守人）后会自动消失
- [ ] 林岚（狐狸，橙红色）从右侧滑入，灰舟（狼，灰色）从左侧滑入
- [ ] 说话时名牌显示“灰舟”（蓝色）/“林岚”（橙色）
- [ ] 灰舟说“……你怎么知道我要去灯塔？”时表情是忧虑；林岚说“别紧张……”时是微笑
- [ ] 长句不会超出对话框，没有文字被截断
- [ ] 鼠标滚轮向上滚或点底部“回退”，能回到上一句；“历史”能看到已读对话

### C2 路线 A：高信任（预期：结局一）
依次选择：
1. 栈桥：**“那就麻烦你带路。”**（+2）
2. 后巷：**“好，只看火漆印。”**（+2）
3. 灯塔：**“信使的职责，就是把信交到收信人手里。”**（+2）

- [ ] 每次选择时，选项出现在人物脸的下方，没有挡住脸
- [ ] 选后左上角弹出“林岚对你的信任提高了”
- [ ] 场景依次切换：栈桥 → 后巷（砖墙木门）→ 灯塔（夜空月亮灯塔）
- [ ] 林岚揭示身份（灯塔看守人），灯塔点亮时有一次暖色闪光
- [ ] 出现黑底结局卡片 **“结局一：灯塔回信”**，随后显示“已解锁结局 N / 3”和“《雾港来信》V0.1 完”
- [ ] 结局结束后自动回到主菜单

### C3 路线 B：中等信任（预期：结局二）
1. 栈桥：**“你为什么要帮我？”**（+1）
2. 后巷：**“我只能告诉你，收信人是灯塔看守人。”**（0）
3. 灯塔：**“我要先知道，收信人到底是谁。”**（0）

- [ ] 出现 **“结局二：半盏灯火”**，灰舟把信放进塔下信箱
- [ ] 结局后回到主菜单

### C4 路线 C：低信任（预期：结局三）
1. 栈桥：**“不用了，我自己找路。”**（−2）——灰舟会先自己去三号码头看一眼，再折回
2. 后巷：**“抱歉，信使不能给任何人看。”**（−2）
3. 灯塔：**“我不会把信交给没有证明身份的人。”**（−2）

- [ ] 选“不用了”后，林岚消失，出现“铁门落了锁”的旁白，然后进入后巷
- [ ] 后巷里林岚说“你果然还是来了……”（这句只有选了拒绝才会出现）
- [ ] 出现 **“结局三：雾中错过”**，回到主菜单

（想看更多混合分支：信任度总和 ≥4 是结局一，1–3 是结局二，≤0 是结局三。例如 +2、0、+2 = 4，也是结局一。）

### C5 存档与读档
- [ ] 游戏进行中，把鼠标移到屏幕底部，点“保存”（或按 Esc 打开菜单 → 保存）
- [ ] 点击任意一个空格子存档，格子上出现缩略图、时间和当前台词
- [ ] 继续玩几句，在后一个选择点做**不同的**选择
- [ ] 点“读取游戏”（主菜单或 Esc 菜单里），选刚才的格子，回到存档时的那一句
- [ ] 读档后再做选择，结局与读档后的选择一致（不是读档前的）
- [ ] 点“快存”后再点“快读”（或 F5 / F9）能正常存取（可选）
- [ ] 关闭游戏再打开，主菜单“读取游戏”里还能看到存档

### C6 重新开始
- [ ] 游戏中按 Esc → “标题菜单” → 确认回到主菜单
- [ ] 再点“开始游戏”，从头开始（信任度已重置：例如上一次拒绝了林岚，新游戏里她不会说“你果然还是来了”，除非你再次拒绝）
- [ ] 打完一个结局回到主菜单后，再点“开始游戏”能正常再玩一遍

### C7 设置
- [ ] “设置”页可以切换 窗口/全屏，文字速度滑条可拖动（往右更快）
- [ ] 语言列表里默认选中“简体中文”（本游戏剧情只有中文）
- [ ] 本版本没有音乐和音效，音量条没有实际声音是正常的

### C8 退出游戏
- [ ] 主菜单点“退出”，出现确认框，点“是”能关闭
- [ ] 游戏中按 Esc → “退出”，同样能关闭
- [ ] 点窗口右上角 ✕ 也能关闭

### C9 视觉检查
- [ ] 三个背景（栈桥 / 后巷 / 灯塔）都能显示，没有黑屏或粉红色“找不到图片”的方块
- [ ] 灰舟和林岚的立绘都能显示，没有缺失
- [ ] 选项文字清晰，在各背景上读得清
