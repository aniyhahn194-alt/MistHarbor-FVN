# 《雾港来信》美术需求说明（ART BRIEF）

版本：V0.2-P1　用途：交给画师 / 美术外包的需求文档。

> **为什么需要这份文档**：目前游戏里所有背景和角色立绘都是由代码（Pillow）绘制的**简易占位图**，质量不足以作为作品集的正式美术。
> 本项目**不会**用低质量占位图冒充正式美术，也**不会**抓取网络图片代替。角色立绘与背景需要专业绘制，界面（UI）部分已由代码原创绘制，可在正式美术到位后再统一微调。

---

## 1. 项目与风格定位

- **类型**：原创 Furry（拟人化动物）视觉小说，轻悬疑、克制的情感氛围；面向一般观众，**无成人内容**，不做过度性化的角色设计。
- **用途**：短期用于 Ren'Py 岗位求职作品展示；长期作为个人作品集，可能公开发布在网页 / itch.io 等平台。
- **世界观**：雾港——常年起雾的港口城市。十年前“雾钟号”沉没，与一封没有送达的信有关。
- **总体视觉**：夜雾港口、冷色基调。主色**深蓝与冷青**，辅以**灯塔暖金色**灯光作为唯一的暖色焦点。雾气、水汽、湿润的石板与灯晕是反复出现的语言。
- **画风方向（仅作氛围参考，不得临摹任何具体作品）**：
  - 日系视觉小说常见的干净线稿 + 柔和赛璐璐 / 半厚涂上色；
  - 背景偏“摄影感的夜景插画”：低饱和、大面积冷色、局部暖光；
  - 角色造型简洁、剪影清晰，毛色分块明确（便于在深蓝背景上辨认）；
  - 避免高饱和荧光色、避免过度写实的兽毛纹理（立绘会被缩到屏幕约 1/3 高度显示）。
- **界面色板**（已在游戏中使用，美术请尽量与之协调）：夜雾深蓝 `#0b1622` `#112233`、冷青 `#5fb8c4`、灯塔暖金 `#f3c677`、文字白 `#eef3f6`。

## 2. 角色设定

### 2.1 灰舟（主角，狼族信使）

| 项目 | 设定 |
| --- | --- |
| 种族 / 年龄 | 灰狼，青年（约 20 岁出头），雾港邮局最年轻的信使 |
| 体型 | 偏瘦、中等身高，肩背挺直但略显谨慎 |
| 毛色 | 灰色为主，口鼻与胸前浅灰 / 近白；耳内侧偏暗粉 |
| 眼睛 | 琥珀 / 金黄色，眼神认真、略带疲惫 |
| 服饰 | 深蓝色信使制服外套（金属纽扣）、**红色围巾**（全画面唯一的高饱和红色，用作视觉锚点）、斜挎**棕色邮包**（搭扣可见） |
| 性格 | 守规矩、谨慎、不轻信陌生人，但内心柔软 |
| 剪影要点 | 立耳、围巾、斜挎包带 |

### 2.2 林岚（狐族，向导 / 隐藏身份为灯塔看守人）

| 项目 | 设定 |
| --- | --- |
| 种族 / 年龄 | 赤狐，与灰舟年龄相仿或稍长 |
| 体型 | 修长、动作轻盈；尾巴蓬松、尾尖偏白 |
| 毛色 | 橙红色为主，胸口 / 脸颊 / 尾尖奶白；耳尖偏黑 |
| 眼睛 | 青绿色，带一点“试探”的审视感 |
| 服饰 | 深青绿色长外套（金线细节）、奶白色内衬；**手提一盏小灯**（暖金光，剧情关键道具） |
| 性格 | 熟悉港口秘密、说话克制、一路试探灰舟；真实身份是灯塔看守人（其父为上一任看守人） |
| 剪影要点 | 尖耳、蓬松大尾巴、手提灯 |

> 两人同屏时：灰舟偏冷（蓝灰），林岚偏暖（橙 + 青绿），在深蓝背景中互相区分；林岚的小灯可作为暖色光源给脸侧一点补光。

## 3. 立绘与表情清单

### 3.1 规格（两位角色统一）

| 项目 | 要求 |
| --- | --- |
| 画布 | 同一角色所有表情使用**相同画布尺寸**，角色脚底落在画布底边；建议 **1800 × 2900 px**（V0.1 占位图为 640 × 1040，游戏内显示约 358 × 582 px，因此有大量冗余分辨率，便于以后升级到 1080p） |
| 视角 | 正面 / 微侧面（3/4）半身至全身均可，但**全部差分必须同一姿势、同一轮廓**，只改变脸部（眼 / 眉 / 嘴 / 耳朵 / 尾巴小动作） |
| 格式 | **PNG（RGBA，8 bit，sRGB，透明背景）**，每个表情一个文件；另附**分层源文件**（PSD / CLIP / KRITA，眼、眉、嘴、耳分层） |
| 命名 | `huizhou_normal.png`、`huizhou_worried.png`、`linlan_normal.png`、`linlan_smile.png` …（小写、下划线；与现有 `script.rpy` 的图像名对应） |
| 体积 | 单张建议 ≤ 3 MB（Web 版会按需下载，过大的立绘会拖慢手机加载） |

### 3.2 表情清单

**现有剧情必需（P0，替换占位图）**

| 角色 | 表情 | 剧情用途 |
| --- | --- | --- |
| 灰舟 | `normal` 平静 | 默认 |
| 灰舟 | `worried` 忧虑 | 发现她知道灯塔、听到旧案时 |
| 林岚 | `normal` 平静 | 默认 |
| 林岚 | `smile` 微笑 | 友善、结局一 |

**后续版本建议（P1，用于增强演出）**

| 角色 | 表情 | 用途 |
| --- | --- | --- |
| 灰舟 | `alert` 警惕、`surprised` 惊讶、`resolute` 坚定、`smile_soft` 淡淡的笑、`tired` 疲惫 | 三次选择的情绪变化、结局 |
| 林岚 | `probing` 试探（半眯眼）、`serious` 认真、`sad` 忧伤、`surprised` 惊讶、`grateful` 感激 | 后巷讲述旧案、结局一 / 二 / 三 |

另需：**站位用 `pos_left` / `pos_right`**（游戏内已有左右站位与滑入动画），无需画不同站位版本；如能提供**耳朵 / 尾巴小动画差分**（各 2 帧）更佳，但不是必需。

## 4. 背景清单

### 4.1 规格

| 项目 | 要求 |
| --- | --- |
| 尺寸 | **1920 × 1080 px**（16:9，游戏当前逻辑分辨率 1280 × 720，按比例缩小） |
| 格式 | PNG（sRGB，无透明）；另附分层源文件；天空 / 灯光 / 雾可分层，便于游戏内做 ATL 动效（光束、雾飘动） |
| 构图 | **画面下方约 1/3 会被对话框遮挡**，主要内容放在上 2/3；角色立绘站在左右两侧（x 约 4% / 96%），**中央留空**给选项菜单；灯塔光源 / 窗口等细节避免与角色面部重叠 |
| 命名 | `bg_dock.png`、`bg_alley.png`、`bg_lighthouse.png` … |

## 6. 交付与验收

1. **交付物**：按上文命名的 PNG + 分层源文件（PSD / CLIP / KRITA）+ 一份 `CREDITS.txt`（画师署名、联系方式 / 主页）。
2. **交付方式**：压缩包 + 文件清单；先交**线稿 / 色稿**小样确认风格，再交最终。
3. **验收标准**：
   - 全部差分画布一致、脚底对齐，叠放时无位移；
   - 在深蓝对话框与选项之上仍有清晰剪影；
   - 在 844 × 390 手机横屏视口（缩放约 0.54）下，角色面部表情仍可辨认；
   - 背景下 1/3 区域信息密度低，不干扰对话文字。
4. **我方会做**：把素材放入 `game/images/`，替换 `script.rpy` 中的占位图引用，重新跑 lint、自动化 testcase 与 Web 构建，并更新 `THIRD_PARTY_NOTICES.md` 与 README。
