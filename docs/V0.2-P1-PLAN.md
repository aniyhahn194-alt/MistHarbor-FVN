# V0.2-P1｜视觉风格与交互界面升级 —— 方案

本轮只做“可测试的第一批 UI 改进”，不加剧情、不加复杂系统、不加音频。剧情文本、三次选择、信任度、三个结局、存读档全部保持不变。

## 1. 现状阅读结论（V0.1 / main）

| 文件 | 现状 | 问题 |
| --- | --- | --- |
| `game/gui.rpy` | Ren'Py 官方模板默认值：橙色强调色、`text_size=26`、`quick_button_text_size=14`、`textbox_height=185`；`@gui.variant small` 里才有放大的字号 | Web 版在 844×390 横屏下缩放比约 0.54：对话字约 14 CSS px，底部快捷菜单字约 7–8 CSS px；浏览器里是否触发 `small` 变体不可依赖 |
| `game/screens.rpy` | 官方模板界面；选项为黑条贴在角色躯干上；快捷菜单贴屏幕最底边；设置页带 13 种语言（剧情只有中文）；**“关于”页还留着模板示例的假署名（Deji / Derik / Mugenjohncel / DaFool / Alessio / Lore / mikey）** | 风格不统一；点按目标小；署名错误 |
| `game/script.rpy` | 剧情、三次 `menu`、`show_ending()` 用 `centered` 显示黑底白字结局卡片 | 结局卡片无设计、不显示结局名之外的信息 |
| `game/options.rpy` | 版本 0.1.0；`build.classify` 已排除 `tests.rpy` | 需升版本号 |
| `game/gui/*`、`game/images/*` | 按钮 / 滑条 / 框来自官方模板的纯色图；背景与立绘是代码绘制的占位图 | 配色与新风格不一致；立绘 / 背景需要专业绘制（见 `docs/ART_BRIEF.md`） |

## 2. 视觉方向

**夜雾港口 · 轻悬疑 · 克制的情感氛围。**

| 角色 | 颜色 | 用途 |
| --- | --- | --- |
| 夜雾深蓝 | `#08101a` `#0b1622` `#112233` `#1a344a` | 对话框、面板、遮罩 |
| 冷青（强调） | `#5fb8c4`（暗 `#2a7f86`） | 边线、标签、已选中项 |
| 灯塔暖金（高亮） | `#f3c677` / 标题 `#f6d58e` | 悬停、标题、结局一、灯点 |
| 正文 | `#eef3f6`（次要 `#aebfcd`） | 文字 |

统一的图形语言：**圆角深蓝面板 + 冷青细边 + 一枚“灯点”**（选项左侧的圆点、姓名框左侧金色竖条、标题分隔线中央、结局页的三盏灯）。

## 3. 本轮改动清单（均用 Ren'Py 原生 Screen Language / Style / ATL）

1. **主菜单与标题**：以夜晚灯塔为底图（压暗 + 暗角），ATL 动态：灯塔光晕呼吸、光束缓慢扫过、两层雾气漂移、标题淡入；左侧渐隐面板托住标题与导航；导航按钮左侧带灯条，悬停变金色。
2. **对话框 / 姓名框**：深蓝半透明对话框，顶部冷青细线；姓名框为圆角面板 + 金色竖条；正文 32px、姓名 36px（V0.1 为 26 / 30）；对话宽度 1100px，两行即可容纳全部台词。
3. **快捷菜单**：移到对话框右上角，按钮高 80px（844×390 横屏下约 43 CSS px，V0.1 约 16），字号 28px（约 15 CSS px，V0.1 约 7.5）；触屏设备隐藏“快存/快读”（F5/F9 仍可用），桌面保留。
4. **选项按钮**：选择时压暗画面，选项为圆角面板 + 灯点，居中、错落淡入；角色缩小到 0.56 并贴向两侧，选项不再盖住脸。字号 32px，按钮高 ≥ 96px。
5. **三个结局卡片**：新的 `ending_card` 屏幕——结局序号、名称（结局一金色 / 结局二冷白 / 结局三冷青灰）、尾声一句、三盏“灯”显示已解锁结局（持久化的 `persistent.endings_seen`）、“返回标题”大按钮；结局一 / 二叠加灯塔光束与光晕（强度不同），结局三无光。点击“返回标题”或任意处（出现 1 秒后才生效，防止连点误触）返回主菜单。
6. **存档 / 设置 / 历史 / 关于 / 确认框 / 提示 / 跳过指示**：统一重绘（Pillow 生成的原创素材，见 `tools/generate_ui.py`）；存档格时间改为短格式；设置页去掉对本作无意义的多语言列表与尚无音频的音量滑条；修正“关于”页的错误署名。
7. **轻量转场与细节**：场景切换改用夜雾色淡入淡出（`fog_fade`）；每个场景有贴地的雾层缓慢漂移（ATL，位于立绘之下）；信封预览改为羊皮纸卡片并带淡入。
8. **不再依赖 `small` 变体**：所有尺寸以手机横屏可读为基准直接设计，桌面与手机共用同一套布局（触屏仅加高导航按钮）。
